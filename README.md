# retail-data-analysis
Project using Excel, Power BI and relational database modelling to analyse sales, expenditure and cash flow across three retail stores.

Multi-Store Retail Data Analysis

This project was completed as part of my Data Modelling coursework at Liverpool John Moores University.

The coursework focused on using Excel, Power BI and relational database modelling to explore how data can support business operations and decision-making.

Project Overview

The project is based on a fictional retail chain with three stores: QuickMart, FreshPicks and EasyShop.

It covers three areas:

1. Excel – Financial Analysis

Monthly sales and expenditure calculations

Cash flow and cumulative profit/loss

Excel formulas and absolute references

Conditional formatting for financial performance

2. Power BI – Business Intelligence

Sales performance dashboards

Expenditure analysis

Cash flow visualisations

Interactive charts and key performance indicators (KPIs)

3. Database Design

Entity identification

Database normalisation (1NF, 2NF and 3NF)

Entity-Relationship Diagrams (ERDs)

Relational schemas, keys and constraints

Tools Used

Microsoft Excel

Microsoft Power BI

Microsoft Word

About This Project

This was a university coursework project that introduced me to different ways of organising, analysing and presenting business data. It also helped me understand how spreadsheet analysis, business intelligence and relational database design can be used together.
